Let’s start with what we’re connecting to. HPC means high-performance computing. A cluster is a group of connected computers, and each computer is a node. In this official NCSA overview, our laptop connects to the head node, which we’ll call the login node.

We organize files, edit scripts, and submit work there. Other users share this node, so heavier analysis goes to compute nodes. We submit a job—a request saying what to run and which resources it needs. The scheduler starts it when those resources become available.

Login and compute nodes can reach the same project files through shared storage. We can prepare a script on one node and run it on another. Connecting with VS Code gives us file access; it doesn’t reserve compute resources. Before connecting, we need an approved account and access to our group’s resources.

ICC · Storage and Data
09 / 45

Home, project, and scratch storage have different purposes. Home, under /u followed by our NetID, is for settings and small personal files. Its quota, or storage allowance, is limited: 100 GiB as the documented soft limit and 103 GiB as the hard limit. Staying above the soft limit for seven days stops new writes until usage falls. The quota can’t be expanded, so large datasets belong elsewhere.

Project storage holds group data, software, and outputs. Capacity depends on the group’s allocation. It has no snapshots—saved filesystem states for restoring earlier files—so important data need separate backups.

Scratch, shown as /scratch/YOUR_NETID, is temporary workspace for files we’re actively working with. Files are typically deleted after 30 days without access, sometimes sooner when space is tight. Purged files can’t be recovered, so move valuable outputs elsewhere.

We’ll use our group’s writable project location. /projects/YOUR_GROUP is a placeholder for its full path, and YOUR_NETID stands for our own NetID. We’ll open the project location, then put demo inside it.

You don't need to memorize every command. These links help when you're working on your own project.

The ICC guide covers this cluster's access, storage, software, and jobs. Missing Semester explains the shell. Microsoft, Slurm, and package documentation cover the individual tools.

For account-specific help, contact ICC support with the job ID, batch script, exact error, and software version. They don't need your password or whole dataset.

Our workflow is to connect, choose a project folder, prepare software, request resources, submit the script, and check logs and results. For real analyses, replace the placeholders and choose suitable software and resources.
